# Strengthify

**Check how strong your password is, right where you type it.**
Strengthify is a free Chrome extension. When you type a password on any website, a small card tells you if it is **Weak**, **Medium** or **Strong**.

- Works offline. Turn off Wi-Fi and it still works.
- Your password is never stored, saved or sent anywhere.
- No account, no sign-up, no settings.

> **Open this page on a computer.** Browser extensions can't be installed from a phone. If you scanned the QR code with your phone, send this page's link to your computer and follow the steps below there.

## Install on Chrome

The steps take about 2 minutes.

### Step 1: Download Strengthify
1. At the top of this GitHub page, click the green **Code** button.
2. Click **Download ZIP**.
3. Wait for the file `strengthify-main.zip` (or similar) to finish downloading.

### Step 2: Unzip the folder
- **Windows:** right-click the ZIP file, then click **Extract All…**, then **Extract**.
- **Mac:** double-click the ZIP file.

Move the unzipped folder somewhere you will keep it, such as your Documents folder. **Don't delete or move it after installing**, because Chrome loads the extension from this folder.

Inside it you will see a folder named **`ext`**. You will need it in Step 4.

### Step 3: Open the Extensions page
Type this in the address bar and press Enter:

```
chrome://extensions
```

### Step 4: Turn on Developer mode and load the folder
1. Turn on **Developer mode** (the switch at the top right).
2. Click **Load unpacked** (top left).
3. Find the unzipped folder and select the folder named **`ext`**.
4. Click **Select Folder** (Windows) or **Select** (Mac).

Strengthify now appears in your list of extensions.

### Step 5: Pin it to your toolbar (optional)
1. Click the **puzzle piece** icon next to the address bar.
2. Click the **pin** icon next to Strengthify.

### Step 6: Reload your open tabs
Extensions only work on pages opened after you install them. Refresh any tabs that were already open, or open a new one.

## How to use it

**On any website:** click a password box and start typing. A small shield badge appears inside the box, and a card appears beside it showing **Weak**, **Medium** or **Strong**.
- Press **Esc** or click the **x** to hide the card.
- Click the shield badge to show or hide it again.

**To test a password without a website:** click the Strengthify icon in your toolbar and type a password in the box.

| Result | What it means |
|---|---|
| Weak | Easy to guess. Choose a different password. |
| Medium | Okay, but a longer or less predictable one is better. |
| Strong | Hard to guess. Use a different strong password for each site. |

---

## Privacy

- Strengthify reads only password boxes, nothing else on the page.
- Your password is checked inside your browser and is never stored, logged or sent over the internet.
- It asks for no special browser permissions.
